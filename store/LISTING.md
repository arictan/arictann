# Store listing texts

Copy-paste ready. Character limits are noted; every text below fits them. Before submitting,
check that nothing promises a feature that's switched off in your build (for example, live
leaderboards need the server from `server/README.md`; until then they're labelled simulated, and
the texts below don't promise real-time players).

Assets in this folder:

| Asset | Files | Store spec |
|---|---|---|
| iPhone screenshots | `ios/1-play.jpg` … `ios/8-map.jpg` (1320×2868) | 6.9" display; App Store Connect scales them for smaller iPhones |
| Android screenshots | `android/1-play.jpg` … `android/8-map.jpg` (1080×1920) | Phone screenshots, 2–8 |
| Feature graphic | `feature-graphic.png` (1024×500) | Google Play, required |
| App icon | `../assets/icon-only.png` (1024×1024) | Both stores |
| Trailer | `trailer.mp4` (1080×1920, 29 s, H.264, silent track) | App preview (15–30 s) / upload to YouTube for Play's promo video |

Rebuild them with `tools/store/screenshots.mjs` and `tools/store/trailer.mjs` (see `tools/store/README.md`).

* **Tags (Google Play):** Stacking, Cooking, Restaurant, Tap, Offline.
* **Support URL / email, privacy policy URL:** required by both stores. Host PRIVACY.md (for
  example on GitHub Pages) and use that link.
